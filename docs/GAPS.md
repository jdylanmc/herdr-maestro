# Architecture gaps

What Herdr-Maestro wanted and could not do with the Herdr app's native
mod surface, `herdr-core` (`hc`), or the agent runtime it observes.

Record a gap when the platform prevents something we actually wanted, not
merely when it is hard. Prefer measurement over suspicion: a gap asserted
without evidence is a guess.

Each entry:

```markdown
### G-NN - <short title>

**Wanted:** what the operator needed.
**Blocked by:** the platform limit, named precisely (API, command, event).
**Evidence:** what was measured, with versions.
**Shipped:** the workaround, or nothing.
**Closes with:** the platform change that would remove the gap.
```

Group entries under `## Herdr app gaps`, `## herdr-core gaps`, and
`## Agent runtime gaps`.
