# Maestro icon font

Maestro uses `JetBrainsMono Nerd Font Mono` for session and action icons.
Herdr loads this mod-local font without a system font installation, including on
Windows. Keep it with the mod when installing or distributing Maestro.

- Source: [Nerd Fonts v3.5.1, JetBrainsMono.zip](https://github.com/ryanoasis/nerd-fonts/releases/download/v3.5.1/JetBrainsMono.zip)
- File: `JetBrainsMonoNerdFontMono-Regular.ttf`, unmodified.
- SHA-256: `f2a5ea6cfab397445ffab00c0370927b66d61e560a05db5db271b42006381c1a`.
